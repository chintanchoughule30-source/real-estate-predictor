EstateIQ

A full-stack Machine Learning web app that predicts residential property prices in Bengaluru, India — built end-to-end from raw dataset to live deployment.

13,320 Training records
0.745 Test R² score
199 Model features
196 Locations encoded
What it does
A user enters four property details — location, area (sq. ft.), BHK, and bathrooms — and the app instantly returns an estimated price in Lakhs (INR) along with a ±10% confidence band. The model was trained on real Bengaluru house listing data from Kaggle, cleaned, and deployed as a REST API.

Challenges Solved
✓
Python 3.14 compatibility scikit-learn, pandas, xgboost had no cp314 wheels on Windows. Replaced entirely with LightGBM native API + Polars + NumPy — all ship pre-built cp314 wheels, zero C compilation needed.
✓
pydantic-core Rust/PyO3 block PyO3 capped at Python 3.13. Pinned pydantic-core==2.46.5 which ships a cp314-win_amd64 pre-built wheel.
✓
Dataset filename mismatch train.py looked for dataset.csv but the file was Bengaluru_House_Data.csv. Fixed the DATASET_PATH constant.
✓
Windows console Unicode errors Arrow and checkmark characters failed on cp1252 Windows console. Replaced with ASCII equivalents.
